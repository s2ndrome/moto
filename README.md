# RIDER CARD

`index.html` 하나가 카드이자 편집기입니다. 기본 상태는 사진·글자가 모두 비어 있고, 클릭할 자리마다 무엇을 입력해야 하는지 회색 안내 문구가 표시됩니다. GitHub Pages로 배포한 뒤 그 페이지에서 바로 수정하면 됩니다 (코드를 열어서 고칠 필요 없음).

## 사용법

- **글자**: 카드에서 원하는 텍스트를 클릭하면 바로 입력 상태가 됩니다. 다른 곳을 클릭하면 자동 저장돼요.
- **사진 교체**: 메인 사진이나 스티커를 클릭하면 화면 아래에 편집 패널이 열립니다. 이미지 주소(URL)를 입력하거나, "내 사진 올리기"로 내 컴퓨터/폰의 사진을 바로 올릴 수 있습니다.
- **스티커 위치**: 카드 위에서 스티커를 손가락/마우스로 드래그하면 바로 위치가 옮겨집니다. 클릭만 하면(드래그 없이) 편집 패널이 열려서 크기·회전 각도를 슬라이더로 조절할 수 있습니다. 어떤 사진을 올려도 자동으로 흰색 테두리가 둘러져서 스티커처럼 보여요.
- **포인트 색상**: 상단 바의 색상 동그라미를 눌러 원하는 색으로 바꾸면 카드의 체크무늬·테두리·포인트 글자색이 한 번에 바뀝니다. 아직 개별 색을 지정하지 않은 칸들은 전부 이 색을 따라갑니다.
- **칸별 색상**: NAME/NICKNAME/BASIC/TEAM 박스와 [외형]/[성격]/[OFF TRACK] 섹션마다 오른쪽 위에 작은 색상 점이 있어요. 그 점을 클릭하면 그 칸만의 색을 따로 지정할 수 있습니다 (전체 포인트 색상을 바꿔도 그대로 유지돼요).
- **배경**: 상단 바의 "배경" 버튼을 누르면 카드 바깥의 체크무늬 배경을 바꿀 수 있어요. 포인트 색상과는 별개로 동작해서 원하는 대로 조합할 수 있습니다.
  - **체크무늬**(기본): 무늬 색을 따로 지정 (지정하지 않으면 포인트 색상을 따라감)
  - **그라데이션**: 색상 2개를 골라 대각선 그라데이션으로
  - **이미지**: 배경 사진 주소를 입력하거나 직접 업로드
- 모든 수정은 **이 브라우저에 자동 저장**됩니다 (새로고침해도 유지). 단, 다른 기기/브라우저에서 열면 보이지 않으니, 완성한 카드는 아래 "HTML 복사"로 따로 백업해두는 걸 권장해요.

## HTML 복사 / 이미지 저장 / 초기화

- **HTML 복사**: 지금 상태의 카드를 `<div>` 코드 조각으로 복사합니다(문서 전체가 아니라 다른 페이지 안에 바로 붙여넣을 수 있는 형태예요). "내 사진 올리기"로 넣은 사진도 그대로 코드 안에 포함되기 때문에, 다른 파일 없이 복사한 코드만으로 바로 사용할 수 있어요.
- **이미지 저장**: 지금 상태의 카드를 PNG 이미지 파일로 다운로드합니다. 외부 이미지 주소(postimg.cc 등)는 사이트 설정에 따라 캡처에서 빠질 수 있으니, 이미지로 저장할 계획이라면 "내 사진 올리기"로 직접 업로드한 사진을 쓰는 걸 권장해요.
- **초기화**: 모든 수정 내용을 지우고 처음 상태로 되돌립니다.

## GitHub Pages로 배포하기

저장소 **Settings → Pages**에서 Source를 `main` 브랜치, 폴더는 `/ (root)`로 설정하면 `index.html`이 웹페이지로 열립니다. 그 배포된 주소를 즐겨찾기 해두고 들어가서 수정하면 됩니다.

## 참고

- 이미지 주소는 [postimg.cc](https://postimg.cc/) 같은 무료 이미지 호스팅의 "직접 링크(Direct link)"를 써도 되고, 파일 업로드 기능으로 바로 올려도 됩니다. 업로드한 사진은 이 브라우저 저장소에 그대로 담기기 때문에 너무 큰 원본 파일(수십 MB급)은 피하는 게 좋아요.
